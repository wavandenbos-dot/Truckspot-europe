# Eerste vaste ondertekende TruckSpot-build

Deze wijziging start éénmalig automatisch de stabiele v1.0.0 APK-build met dezelfde app-ID en beveiligde ondertekening. De vier GitHub repository secrets zijn door de gebruiker ingesteld. Voor volgende versies wordt de workflow handmatig gestart met een hogere `version_code`.

De privésleutel staat uitsluitend in GitHub Secrets; voer die nooit in als broncode of in chat.
