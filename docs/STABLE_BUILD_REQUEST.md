# TruckSpot Europe 1.0.1 — build met verbeterde parkeerzoekfunctie

Deze update herstelt het zoeken naar vrachtwagenparkings met expliciet vermelde overnachtingstoestemming. Het ingebouwde onderzoeksbestand met onbevestigde locaties stopt de online zoekopdracht niet langer. De Overpass-zoekopdracht vraagt gericht om nachtovernachtingstags en verbergt onbevestigde punten.

Android package: `eu.truckspot.europe.stable`; `versionCode 101`; `versionName 1.0.1`; ondertekening via bestaande GitHub Secrets. Deze wijziging activeert de gecorrigeerde Android-build.
