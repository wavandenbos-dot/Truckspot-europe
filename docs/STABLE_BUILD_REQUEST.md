# TruckSpot Europe 1.0.1 — vaste Android-update

De app haalt voortaan echte vrachtwagenovernachtingslocaties uit de online bron in plaats van direct te stoppen bij de onbevestigde Europese onderzoekscoördinaten. Niet geverifieerde onderzoeksplekken worden niet getoond als overnachtingsparking. Alleen officiële/verifieerbare parkeerplaatsen met expliciete overnachtingsinformatie of goedgekeurde gedeelde locaties worden getoond.

Build op dezelfde vaste Android app-ID `eu.truckspot.europe.stable`, dezelfde GitHub Secrets voor Android ondertekening, `versionCode=101`, `versionName=1.0.1`. Dit is een update boven 1.0.0, geen nieuwe app.
